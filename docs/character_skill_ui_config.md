神圣领域：法术技能。若可用，在技能面板点击发动并确认消耗水晶后：

式神咒束：响应技能（代应战截流）。当目标队友受到主动攻击，且该攻击可以被应战时：前端在后台进行条件校验：判断你是否处于［式神形态］，以及我方战绩区是否至少有1［宝石］和1［水晶］。
