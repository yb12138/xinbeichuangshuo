前端交互协议约束（强制，2026-05）：
1) `target_picker` 选项必须使用结构化字段 `option.target_id` 标识目标玩家；不得依赖 `label`、`button_label` 文本承载目标身份。
2) 取消语义必须来自 `presentation.cancel_policy`（如 `abort/decline/back`），不得再依赖 `Prompt.Cancelable` 或上下文 `cancelable` 兜底字段。
3) 前端禁止通过 `label/name/role` 文本推断目标玩家（包括但不限于 marker 匹配、字符串包含匹配）；目标映射必须仅依据结构化 ID 字段。
