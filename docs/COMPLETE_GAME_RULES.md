# 《星杯传说》完整游戏规则说明书

> **用途**：本文是给另一个 AI / 实现者直接做游戏用的完整规则规格。  
> **口径**：以本仓库当前可玩实现为准（6 人 3v3，35 名角色，150 张基础牌）。官方说明书中与本项目冲突的条目，一律以本文「本项目裁定」为准，并在对应位置标明。  
> **不要依赖**：源码结构、Go 类型名、前端协议。本文只讲「游戏世界里发生了什么」。

---

## 0. 给实现者的阅读顺序

1. 先读 **第 1–7 节**：弄清这是什么游戏、怎么赢、桌上有哪些资源。
2. 再读 **第 8–11 节**：弄清牌库、回合、五种行动。
3. 然后读 **第 12–21 节**：攻击、法术、伤害时间轴、治疗、技能总则。这些是所有角色共享的「物理定律」。
4. 最后读 **第 22–24 节**：35 名角色的完整技能。没有这些，游戏能跑但没有角色差异。
5. 实现时反复对照 **第 25 节歧义裁定**。同一时点多个效果同时触发时，必须按该节顺序结算。
6. 对战页布局参考图见同目录 [`battle_page_reference.png`](battle_page_reference.png)。

**实现最低可行版本（MVP）建议**：

- 必须：双胜利条件、士气/星杯/战绩区、手牌上限与爆牌、五种行动、攻击应战、圣光/圣盾/中毒/虚弱/魔弹、伤害时间轴 ①–⑥、治疗抵伤。
- 然后：独有技绑定、启动技与额外行动、无法行动。
- 最后：逐个角色接入技能。没有角色技能时，基础对战已经能玩。

## 1. 游戏是什么

《星杯传说》是一款 **阵营对抗卡牌对战**。玩家分成红、蓝两队，共用 150 张基础牌库。每人扮演一名角色，用手牌发动攻击或法术，同时用阵营资源合成「星杯」。

这不是扣血游戏。角色没有生命值。伤害的表现是 **强制摸牌**；摸牌超过手牌上限会 **爆牌弃牌**，每弃 1 张，该角色所在阵营 **士气 -1**。把对方士气打到 0，或己方合成 5 个星杯，立即获胜。

核心循环：

```
打出攻击/法术 → 对方应战或承受 → 命中则摸牌 → 可能爆牌扣士气
           ↘ 主动攻击命中还可能给己方战绩区加宝石
购买/合成/提炼 → 积累星石 → 合成星杯 → 同时扣对方 1 点士气
```

## 2. 术语表

| 术语 | 含义 |
|---|---|
| 基础牌 | 150 张公用牌。手牌、摸牌、弃牌、打出，一律指基础牌。 |
| 卡 | 非基础牌的标记物：角色卡、治疗卡、星石卡、星杯卡、指示物、专属卡。 |
| 系别 | 牌的元素：地、水、火、风、雷、光、暗。 |
| 命格 | 牌/角色的流派：幻、咏、血、技、圣。 |
| 战绩区 | 阵营公共区，放宝石和水晶，上限 5。 |
| 星石 | 宝石 + 水晶的统称。 |
| 能量 | 提炼到角色面前的星石。宝石能量、水晶能量分开计数。 |
| 治疗 | 角色身上的护盾点数，可在承受伤害时抵消摸牌。 |
| 主动攻击 | 消耗【攻击行动】打出的攻击。 |
| 应战攻击 | 被攻击时打出同系攻击牌，把攻击转给攻击方一名队友。不消耗攻击行动。 |
| 一般行动 | 攻击行动、法术行动。 |
| 特殊行动 | 购买、合成、提炼。 |
| 启动 | 行动阶段开始时发动的技能。不消耗行动，但启动后本回合不能再执行特殊行动。 |
| 额外行动 | 技能在一次行动结束后追加的攻击行动或法术行动。 |
| 基础效果 | 放在角色面前、持续一段时间的基础牌效果（中毒/虚弱/圣盾/封印/赐福等）。 |
| 专属效果 | 角色专属卡形成的持续效果，不能被「移除基础效果」的技能移除。 |
| 爆牌 | 手牌超过上限，必须弃到上限；每弃 1 张，所在阵营士气 -1。 |
| 横置 / 转正 | 角色姿态。横置通常表示进入某种形态；转正表示脱离该形态。 |
| 独有技 | 必须打出印有该角色独有技的那张基础牌才能发动的技能。 |
| 必杀技 / 大招 | 需要消耗能量的技能。标水晶的可用宝石代替；标宝石的只能用宝石。 |
| 强制 | 该效果不可跳过，必须执行。 |
| 展示 | 把牌亮给所有人看。 |
| 丢失目标 | 技能找不到合法目标，因此不能发动。 |
| 不完全发动 / 部分发动 | 有合法目标，但效果没完全兑现。技能仍可发动。 |
| 溢出 | 超过上限的部分被舍弃，仍视为发动成功。 |

## 3. 对局规模、座位、选角

### 3.1 人数与阵营

| 模式 | 人数 | 阵营 | 初始/上限士气 |
|---|---|---|---|
| 本项目主模式 | 6 人 | 3 红 3 蓝 | 15 |
| 官方也支持 | 4 人 | 2 红 2 蓝 | 15 |
| 官方也支持 | 8 人 | 4 红 4 蓝 | 18 |

本项目引擎硬上限为 6 人，房间校验为每队 1–3 人。**做完整游戏时以 6 人 3v3 为标准规格。**

### 3.2 座位与行动顺序

玩家围坐，按座位顺序轮流行动。下家 = 座位顺序中的下一位。

- **本项目座次**：开局时把红蓝交错排开（`RBRBRB` 或 `BRBRBR`），避免同阵营三人连坐。
- **官方比赛座次**：6 人为 `RBBRRB`。
- **右手方向**：沿座位顺序的「前一位」（索引递减）。魔弹默认沿右手方向传给「右手边最近的一名对手」。
- **左手方向**：座位顺序的下一位。
- **多人同时结算**：从当前回合角色开始，沿座位逆时针依次结算。

### 3.3 先手

本项目：开局后在全体玩家中 **随机** 决定先手。

官方：阵营卡中有一张印有 First Player 的红卡，抽到该卡者为先手。

### 3.4 选角

本项目联机：进入房间后每人自选阵营和角色，**角色不可重复**。也可随机发一名角色。

官方另有 CM01 / RD / BP / 3 选 1 / 暗黑议会 / 酒馆等多种选角。做游戏时选角可以简化为：

1. 每人从 35 名角色池中不重复选择；或
2. 系统随机分配。

官方限制：**红莲骑士与圣殿骑士不能同时在角色池；圣女与矜贵之女不能同时在角色池。** 本项目 35 人池不含圣殿骑士、矜贵之女，因此当前无需处理。

## 4. 胜利条件（立即结束）

任一条件达成，游戏立刻结束，不再结算后续效果：

1. **士气胜利**：对方阵营士气 ≤ 0。
2. **星杯胜利**：己方星杯 ≥ 5。

合成星杯时会同时让对方士气 -1。若因此把对方士气打到 0，也算胜利。

平局：本项目未定义同时达成的处理。实现时若同一结算步骤内两边同时满足胜利条件，建议判 **先被检查到的条件** 生效；更稳妥的是「士气 0 优先于星杯 5」，因为士气下降往往是合成的附带效果。推荐：**同一瞬间两边都赢则判平局**。

## 5. 开局流程

1. 放好双方台面（战绩区、星杯区、士气区）。双方士气 15，星杯 0，星石 0。
2. 确定阵营与座位，每人展示阵营。
3. 每人选择一名角色。把该角色需要的专属卡、指示物发给该玩家。游戏开始时未获得的指示物背面朝上；获得后翻到正面。
4. 将 150 张基础牌洗匀，作为公用牌库。牌库用尽时，把弃牌堆洗匀组成新牌库。
5. 按座位顺序，每人从牌库顶摸 **4 张** 作为起始手牌。
6. 触发「游戏初始时」技能（见第 10.1 节）。
7. 随机（或按先手标记）决定第一名行动的玩家，进入其回合。

## 6. 公共区域

每方阵营有三块公共区：

### 6.1 战绩区

- 放宝石和水晶。两者都是星石。
- 上限 **5 个星石**。已满时，任何「加星石」效果都不再增加，也不替换。
- 主动攻击命中：己方战绩区 +1 **宝石**（未满时）。
- 应战攻击命中：己方战绩区 +1 **水晶**（未满时）。
- 某些技能也会给战绩区加星石，同样受上限约束。

### 6.2 星杯区

- 初始 0，达到 5 立即胜利。
- 主要来源：特殊行动【合成】。圣弓的【圣煌辉光炮】等技能也能获得。

### 6.3 士气区

- 初始 15，上限 15。
- 爆牌每弃 1 张 -1。
- 合成星杯时对方 -1。
- 部分技能直接扣士气，或阻止/减少士气下降。

### 8.3 独有技怎么用

一张基础牌可以印 0–2 个独有技，分别绑定两名角色。

规则：

- 只有 **印在这张牌上的那个角色** 打出这张牌时，才能发动对应独有技。
- 其他角色打出同一张牌，只当普通攻击/法术，不能发动独有技。
- 独有技是「打出该牌时」的附加效果，不是另一次行动。
- 法术类独有技（如天使之墙、治疗术、五系封印）把该牌当对应法术使用。
- 攻击类独有技（如血腥咆哮、疾风技）在把该牌当主动攻击打出时发动。

## 9. 五种行动

每位玩家在自己的 **行动阶段必须执行恰好 1 个行动**（额外行动另计）。五种行动如下。

### 9.1 攻击行动（一般行动）

指定一名可被攻击的对手，打出 1 张攻击牌，或发动「视为一次攻击」的技能。这是 **主动攻击**，消耗本次攻击行动。

不能攻击：

- 己方队友（除非技能明确允许）。
- 处于【潜行】等「不能成为主动攻击目标」状态的对手。
- 技能临时禁止的目标（例如魔弓【魔贯冲击】不能攻击手牌已达上限的对手）。

详见第 12 节。

### 9.2 法术行动（一般行动）

打出 1 张法术牌，或发动法术技。消耗本次法术行动。

- **圣光不能作为主动法术行动打出**，只能在被攻击或被魔弹时响应使用。
- 中毒、虚弱、圣盾：放到目标面前，成为基础效果。
- 魔弹：立即开始传递链，不放置在场上。
- 基于另一次攻击/法术「之上」再发动的法术，不视为再消耗一次法术行动。

### 9.3 购买（特殊行动）

**前置条件**：摸 3 张后手牌不超过上限（即当前手牌 ≤ 上限 - 3）。否则不能购买。

效果：

1. 摸 3 张牌（非伤害摸牌）。
2. 己方战绩区 +1 宝石 +1 水晶。
3. 若战绩区已有 5 个星石：仍可购买并摸牌，但不加星石。
4. 若战绩区已有 4 个星石：只能再放 1 个，由玩家选择放宝石还是水晶。通常选宝石。
5. 冒险家【地下法则】把奖励改成 +2 宝石。

### 9.4 合成（特殊行动）

**前置条件**：

- 摸 3 张后不超过手牌上限。
- 己方战绩区星石 ≥ 3。

效果：

1. 摸 3 张牌。
2. 从战绩区移除 3 个星石。本项目实现为 **先扣宝石，宝石不够再扣水晶**。
3. 己方星杯 +1。
4. 对方士气 -1。
5. 立即检查胜负。

### 9.5 提炼（特殊行动）

**前置条件**：

- 战绩区至少有 1 个星石。
- 自己的能量未达上限。

效果：从战绩区拿走 **1 或 2** 个星石放到自己面前，成为能量。不能超过自己的剩余能量空位。玩家自行选择拿宝石还是水晶。

注意：即使还能提炼，只要没有其他合法一般行动，仍可宣告【无法行动】（见第 20 节）。提炼本身不阻止宣告无法行动。

### 9.6 特殊行动锁定

以下情况本回合不能再执行特殊行动：

- 本回合已经发动过启动技。
- 本回合宣告过无法行动并完成换牌。
- 某些形态明确禁止（如格斗家【百式幻龙拳】、圣弓【圣煌形态】下执行特殊行动会脱离形态）。

## 10. 回合结构

一个回合严格按下列阶段推进。未写「无实际意义」的阶段都有强制结算。

### 10.1 游戏初始时（仅整局一次）

在发完起始手牌后、第一回合开始前触发。已知触发：

| 角色 | 效果 |
|---|---|
| 仲裁者 | +2 水晶能量 |
| 勇者 | +2 水晶能量 |
| 圣弓 | +1【圣煌辉光炮】、+2 水晶；治疗上限 +1 |
| 英灵人形 | 获得 3 个【战纹】 |
| 染污者 | 不在本项目 35 人池（若接入：+1 水晶，治疗上限恒为 0） |

其余角色若技能写「游戏初始时」，也在此时触发。

### 10.2 回合开始前

宣言即将开始。可发动的响应：天使【天使之歌】等。

### 10.3 回合开始时

宣言回合开始。形态伤害、指示物增长等多在此时结算，例如：

- 血之巫女【流血形态】：对自己造成 1 点法术伤害。
- 仲裁者【仲裁仪式】：+1 审判。
- 女武神【军神威光】。

### 10.4 行动阶段开始前（基础效果结算）

按下列顺序：

1. 【五系束缚】（若有）先于虚弱结算。
2. 【中毒】：对该角色造成 1 点法术伤害③，然后移除此牌。
3. 【虚弱】：选择「跳过行动阶段」或「摸 3 张牌后继续」。无论选哪项都移除虚弱。
4. 苍炎魔女【魔女之怒】等到下个行动阶段开始前结束。

本项目裁定：**同一角色面前同名基础效果最多 1 个。中毒不可叠加。**  
（部分官方文本允许多个中毒；本项目不允许。）

### 10.5 行动阶段开始时

- 检查仲裁者是否必须发动【末日审判】（审判已达上限）。
- 勇者【挑衅】：本阶段必须主动攻击指定来源，否则跳过行动阶段。
- 暗杀者【潜行】、魔剑士【暗影凝聚】、勇者【精疲力竭】等到此时结束。
- **启动技窗口**：每回合最多启动一次。启动后必须还能执行一次攻击或法术；否则不能启动。
- 可在启动前或启动后（若启动不能增加行动可能）宣告无法行动。

### 10.6 行动阶段

执行恰好 1 个行动（攻击 / 法术 / 购买 / 合成 / 提炼），除非被虚弱/五系束缚/挑衅跳过。

### 10.7 行动结束时

大量响应技在此时询问（法术激荡、风怒追击、不朽、神圣启示、武者残心等）。

### 10.8 额外行动阶段

若上一步产生了 +1 攻击行动 / +1 法术行动，进入额外行动。额外行动：

- 仍是一次完整的攻击或法术（含应战、伤害、再触发行动结束）。
- 可能继续产生更多额外行动，形成连锁。
- 额外行动通常 **不能** 改执行特殊行动。
- 若额外行动带元素约束（例如「风系攻击行动」），必须打出该系攻击牌或等价效果。
- 若额外行动没有合法执行手段，宣告无法行动则 **跳过该次额外行动**，不执行「弃牌重摸」。

### 10.9 回合结束时 / 结束阶段

形态脱落、自动填充、月之轮回、胜利交响诗等。然后右手边下一位玩家开始回合。

## 11. 攻击系统（核心）

### 11.1 主动攻击

回合内打出攻击牌指定一名对手。无特殊说明，回合内攻击都视为主动攻击。

「视为一次主动攻击」= 消耗攻击行动。若该效果来自法术，则同时视为消耗了法术行动。

攻击性质 **不能转换**：主动就是主动，应战就是应战。

### 11.2 防守方三项选择

被攻击的玩家必须选择一项：

1. **应战**：打出 1 张 **同系攻击牌**，或打出 **暗灭**。视为本次攻击未命中，并对 **攻击者的一名队友** 发起应战攻击。
2. **防御**：打出 1 张【圣光】，视为未命中。场上的【圣盾】不是手牌防御，见下。
3. **承受**：什么也不做，攻击命中。

### 11.3 圣盾的强制抵挡

若目标面前有【圣盾】：

- 玩家仍可先选择应战或打出圣光。
- 若选择承受，则 **必须** 移除圣盾，视为未命中。不能保留圣盾硬吃伤害。
- 手牌里的圣盾 **不能** 当作响应牌打出；圣盾必须事先放在场上。
- 某些技能「无视圣盾」时，承受不会触发圣盾。

### 11.4 应战细则（本项目裁定）

- 应战目标必须是 **攻击者的队友**，不能打回攻击者本人，也不能打给应战者自己的队友。
- 若攻击者没有存活队友，则无法应战（只能圣光/圣盾/承受）。4 人局每队 2 人时尚可应战；若做成 1v1 则应战无法成立。
- 应战攻击命中时，应战方阵营战绩区 +1 **水晶**（不是宝石）。
- 应战不消耗应战者的攻击行动。
- 被应战的那名队友可以再次应战、圣光、圣盾或承受，形成链式应战。

### 11.5 暗灭

- 暗灭可以应战 **除暗灭以外** 的任何系别攻击。
- 暗灭 **不能被应战**，只能用圣光或圣盾抵挡，或直接承受。
- 暗灭伤害仍为 2。

### 11.6 命中与未命中

- 承受（且圣盾未抵挡）= 命中。
- 应战、圣光、圣盾、或技能强制未命中 = 未命中。
- **强制命中**：跳过应战与圣光/圣盾（除非该强制命中技能另有说明），直接进入命中。
- **无法应战**：不能选应战，但仍可用圣光/圣盾（除非同时无视圣盾）。
- 即使用治疗把伤害降到 0，只要判定为命中，仍会给战绩区加星石。

### 11.7 命中奖励

| 攻击类型 | 战绩区奖励 |
|---|---|
| 主动攻击命中 | +1 宝石 |
| 应战攻击命中 | +1 水晶 |
| 战绩区已有 5 星石 | 不加 |

## 12. 法术系统

### 12.1 中毒

- 法术行动：放到任意一名角色面前（可对自己或队友）。
- 该角色下次行动阶段开始前：受 1 点法术伤害③，然后中毒进弃牌堆。
- 本项目：目标已有中毒则不能再放。

### 12.2 虚弱

- 法术行动：放到任意一名角色面前。
- 该角色下次行动阶段开始前必须选择：
  1. 跳过行动阶段（直接进入回合结束相关流程）；
  2. 摸 3 张牌【强制】，然后正常执行一个行动。
- 无论选哪项都移除虚弱。
- 目标已有虚弱则不能再放。

### 12.3 圣盾

- 法术行动：放到任意一名角色面前。
- 该角色遭受攻击或魔弹时，移除圣盾，视为未命中。
- 目标已有圣盾则不能再放。
- 天使之墙等「当作圣盾使用」的牌，放上场后按圣盾结算。

### 12.4 圣光

- 只能在「你被攻击」或「魔弹指向你」时打出。
- 抵挡后视为未命中 / 魔弹终止。
- 不能主动当法术行动打出。

### 12.5 魔弹

使用魔弹（或把某牌当魔弹使用）时：

1. 基础伤害 2 点法术伤害。
2. 目标 = 使用者右手边最近的一名对手。魔法少女【魔弹掌控】可改为逆向（左手方向最近对手）。
3. 目标选择一项：
   - 承受：受到当前伤害。
   - 打出 1 张魔弹【展示】：视为由他使用魔弹继续传递，伤害 +1，对他视为未命中。
   - 打出圣光【展示】或移除面前圣盾：抵挡，链条终止。
4. 同一轮传递中，每名角色只能参与一次（发起者也算已参与）。
5. **本项目裁定**：当参与人数达到场上存活人数时，链条 **结束**，不再继续传递。  
   （官方文本是「该轮结束但伤害不清零继续传」。本项目不继续传。）
6. 魔弹可被圣光或圣盾终止。
7. 每传递一次，伤害额外 +1。

魔法少女还可以把地系或火系牌当魔弹使用（【魔弹融合】）。

## 13. 伤害时间轴（必须按此实现）

所有伤害都走 ①–⑥。技能文本后的 ①②③④⑤⑥ 就是这些时点。

| 时点 | 名称 | 发生什么 |
|---|---|---|
| ① | 发动阶段 | 宣言攻击或法术。可修改「无法应战 / 强制命中 / 伤害预修正」。 |
| ② | 命中判定 | 应战、圣光、圣盾、强制命中在此时尘埃落定。命中则准备加星石。未命中则走未命中技能，不造成伤害。 |
| ③ | 计算伤害 | 算出将造成的伤害量。加减伤、元素吸收、血气屏障等都在此时。 |
| ④ | 治疗响应 | 承受者选择用几点治疗抵消。每 1 治疗抵 1 点伤害。 |
| ⑤ | 实际产生伤害 | 治疗抵消后的最终伤害量确定。蝶舞者【毒粉】【镜花水月】等看这个值。 |
| ⑥ | 实际承受 | 按最终伤害摸等量的牌。爆牌、士气、反噬、水影（摸牌前）等在此时。 |

**同一时点多个技能**：

1. 按技能文本书写顺序和时间轴数字。
2. 插入结算：条件一旦满足就立刻先结算（后发先至）。例：应战展示牌触发封印师封印伤害，先结算封印，再结算未命中。
3. 自身技能先于外来专属卡技能。
4. 其余由当前玩家自行决定顺序。
5. 多名目标同时被选中：从当前回合角色起逆时针依次结算。

**伤害只存在于角色与角色之间。** 卡牌不会对卡牌造成伤害。造成伤害者是玩家，承受伤害者是玩家。

## 14. 摸牌、手牌上限、爆牌、士气

### 14.1 两种摸牌

| 类型 | 来源 | 能否用治疗抵御 |
|---|---|---|
| 伤害摸牌 | 每承受 1 点伤害摸 1 张 | 能（在④抵消后，⑥少摸） |
| 非伤害摸牌 | 购买、合成、虚弱摸 3、狙击等 | 不能 |

牌库空了：把弃牌堆洗匀当新牌库。若牌库和弃牌堆都空了，摸不到的部分作废。

### 14.2 手牌上限

默认 6。部分技能会改（怜悯恒定 7、潜行 -1、仲裁仪式恒定 5 等）。

盖牌区、祝福区、充能、茧、剑魂、遗迹等 **不是手牌**，不计入上限。

### 14.3 爆牌

手牌 > 上限时，持有者自己选择弃牌，弃到恰好等于上限。

- 弃牌面朝下，别人不能看。
- 每弃 1 张，所在阵营士气 -1。
- 任何原因导致爆牌都扣士气，包括手牌上限突然降低。

### 14.4 士气下限技能

某些技能规定「对方士气最少为 1」或「我方士气最少为 1」。此时士气下降会被截断，不能用这种方式取胜，直到该效果结束。

## 15. 治疗

### 15.1 获得

由技能发放。默认上限 2，溢出舍弃。部分角色改变上限：

| 角色 | 治疗上限 |
|---|---|
| 默认 | 2 |
| 圣女【怜悯】不改变上限 | 2 |
| 圣枪骑士【神圣启示】（己方星杯 ≥ 对方时） | 3 |
| 瘟疫法师【圣渎】 | 5，且不能抵御攻击伤害 |
| 红莲骑士【腥红信仰】 | 4，且只能抵御自己造成的伤害 |
| 神官【圣使守护】 | 6，且每次抵御最多用 1 点 |
| 圣弓【天之弓】 | 3 |
| 圣光祈愈 | 可暂时无视上限加到最高 5 |

### 15.2 使用法则

- 承受伤害时，玩家 **可以** 用治疗抵，也可以不用。选择权在承受者。
- 顺序：先确定③的伤害，再④选择抵多少。
- 可以只抵一部分。
- 抵到 0 伤害仍算攻击命中（若②已判定命中）。
- 治疗只能抵伤害摸牌，不能抵购买/合成/虚弱等非伤害摸牌。

### 15.3 特殊治疗规则

- 血蔷薇庭院在场：所有角色的治疗无法用于抵御伤害。
- 神官每次最多用 1 点治疗抵御。
- 瘟疫法师的治疗不能抵御攻击伤害。
- 红莲骑士的治疗只能抵御自己造成的伤害。

## 16. 能量与必杀技支付

### 16.1 能量来源

主要来自提炼。部分技能直接 +宝石 / +水晶能量。

### 16.2 支付规则

| 技能标注 | 可以支付的能量 |
|---|---|
| ［水晶］ | 1 水晶 **或** 1 宝石 |
| ［宝石］ | 只能 1 宝石 |
| X 个［水晶］ | X 点，宝石可替代水晶 |
| ［持续］［宝石］ | 通常还伴随横置进入形态 |

### 16.3 上限

默认 3。贤者【智慧法典】为 4。达到上限不能提炼。溢出的获得被舍弃，除非技能写「无视上限」并另给绝对上限。

## 17. 基础效果与专属效果

### 17.1 基础效果

持续放在某角色面前的基础牌，例如：中毒、虚弱、圣盾、五系封印、威力赐福、迅捷赐福、天使之墙。

规则：

- 同一角色面前， **同名** 基础效果最多 1 个，除非效果写明可多个。
- 触发后通常进入弃牌堆。
- 「移除基础效果」的技能（风之洁净、天使之歌）可以移除它们。

### 17.2 专属效果

角色专属卡形成的场上效果，例如：五系束缚、血蔷薇庭院、同生共死、挑衅、灵魂链接、永恒乐章。

- 不能被「移除基础效果」移除。
- 有自己的触发和移除时机。

### 17.3 本项目基础状态一览

| 状态 | 叠加 | 触发时点 | 效果 |
|---|---|---|---|
| 中毒 | 唯一 | 行动阶段开始前 | 1 点法术伤害，然后移除 |
| 虚弱 | 唯一 | 行动阶段开始前 | 跳过 或 摸 3 继续，然后移除 |
| 圣盾 | 唯一 | 被攻击/魔弹且选择承受 | 未命中并移除。不可放弃 |
| 五系束缚 | 唯一 | 行动阶段开始前，先于虚弱 | 跳过下个行动阶段；或摸 (2+X) 取消（X=场上封印数，最高 2） |
| 元素封印 | 同系唯一 | 打出或展示对应系别牌 | 3 点法术伤害，然后移除 |
| 挑衅 | 唯一 | 行动阶段 | 必须主动攻击来源，否则跳过该行动阶段 |

## 18. 技能系统总则

### 18.1 按来源分类

| 类型 | 含义 |
|---|---|
| 普通技 | 不耗能量 |
| 独有技 | 必须打出对应独有牌 |
| 专属技 | 通过专属卡发动 |
| 必杀技 / 大招 | 消耗能量 |

### 18.2 按发动方式分类

| 类型 | 何时发动 | 是否消耗行动 |
|---|---|---|
| 被动技 | 条件满足自动发动 | 否 |
| 响应技 | 条件满足时询问是否发动 | 否 |
| 启动技 | 仅自己行动阶段开始时 | 否，但锁特殊行动 |
| 法术技 | 自己行动阶段，视为法术行动 | 是 |

### 18.3 启动限制

- 每回合最多启动 **一次**（即使有多个启动技）。
- 只能在行动阶段开始时发动。
- 启动后本回合不能执行特殊行动。
- 启动后必须还能执行攻击或法术；否则不能启动。
- 启动视为抹杀购买和合成的可能性，用于无法行动判定。

### 18.4 重复回应

同一时刻， **同一个技能** 只能触发一次。例：狂战士不能因拥有 2 个宝石而发动两次【撕裂】。

不同技能在同一时点可以都发动，由玩家选顺序（除非互斥，如天枪不能和圣击同时发动）。

### 18.5 发动条件 vs 发动效果

- 括号里的褐色条件是 **发动条件**。不满足则完全不能发动。
- 后面的黑色文本是 **效果**。效果没完全兑现仍可发动。

例：

- 弓之女神【贯穿射击】「弃 1 张法术牌」是条件：没法术牌就不能发动。
- 天使【天使祝福】目标是角色：对方没手牌只是不完全发动，仍可发动。
- 天使【风之洁净】目标是场上基础效果：场上没有基础效果 = 丢失目标，不能发动。

### 18.6 回合限定

标有［回合限定］的技能每回合只能成功发动一次。

## 19. 无法行动

行动阶段必须执行一个行动。若完全没有合法行动，可以宣告无法行动。

### 19.1 流程

1. 展示全部手牌。
2. 弃掉全部手牌（此弃牌 **不扣士气**，因为是规则换牌，不是爆牌）。
3. 从牌库摸回相同张数。
4. 本回合不能执行特殊行动。
5. 然后继续这次行动阶段（用新手牌执行一个一般行动）。
6. 此过程不触发封印师的封印。

若手牌为 0：直接结束行动阶段，并锁定特殊行动。

### 19.2 什么时候不能宣告

- 手里有能打出的攻击牌，且存在合法攻击目标。
- 手里有能主动使用的法术牌，且存在合法目标。
- 有可发动的法术技 / 行动技能。
- 玩家不能主动弃牌或拒绝行动来制造无法行动。

可以宣告的情况：

- 只剩圣光（圣光不能主动打出），且购买/合成会爆牌。
- 即使还能提炼，也可以宣告。
- 被勇者挑衅时：不能用无法行动逃避，必须跳过回合或按挑衅攻击。

### 19.3 额外行动中的无法行动

额外行动没有合法执行手段时，宣告无法行动 = **跳过该额外行动**，不弃牌重摸。

## 20. 结算顺序速查

1. 按文本从左到右、按 ①→⑥。
2. 多目标：当前回合角色起逆时针。
3. 插入结算后发先至。
4. 自身技能 > 外来专属卡。
5. 同名技能同一时点只一次。
6. 其余由当前相关玩家选择顺序。
7. 胜负在士气或星杯变化后立即检查。

### 20.1 常见插入例子

## 25. 实现约束与歧义裁定（必读）

把这一节当作「物理引擎的单元测试规格」。

### 25.1 必须做对的 20 条

1. 没有生命值。伤害 = 摸牌。爆牌弃牌才扣士气。
2. 攻击牌伤害恒为 2，再叠技能修正。
3. 主动命中 +宝石，应战命中 +水晶，战绩区满 5 不加。
4. 治疗抵到 0 仍算命中，仍加星石。
5. 圣光只能响应，不能当主动法术。
6. 手牌圣盾不能当响应牌；场上圣盾在选择承受时强制触发。
7. 暗灭可应战任何非暗灭；暗灭不可被应战。
8. 应战目标 = 攻击者的队友，不是任意角色。
9. 同名基础效果每角色最多 1 个。中毒不叠加。
10. 水晶费用可用宝石付；宝石费用不能用水晶付。
11. 购买/合成必须「摸 3 后不爆牌」才允许执行。
12. 合成先扣宝石再扣水晶，然后星杯 +1、对方士气 -1，立即判胜负。
13. 启动每回合一次，启动后禁止特殊行动。
14. 同技能同时刻只能发动一次。
15. 独有技必须「这张牌印着这个角色的这个技能」。
16. 牌库空了洗弃牌堆；仍空则少摸。
17. 盖牌区不是手牌，不参与爆牌。
18. 无法行动换牌不扣士气，且本回合锁特殊行动。
19. 额外行动无法执行时跳过，不换牌。
20. 胜负在士气/星杯变化后立即结束，不再继续后面的技能。

### 25.2 与部分官方文本不同、以本项目为准

| 议题 | 本项目 |
|---|---|
| 中毒叠加 | 不可叠加 |
| 魔弹传完全场后 | 链条结束，不继续第二轮 |
| 6 人座次 | 红蓝交错，不是 RBBRRB |
| 先手 | 随机 |
| 应战目标 | 仅攻击者队友 |
| 选角 | 房间自选/随机，角色不重复 |
| 角色池 | 35 名，见第 22 节 |

### 25.3 建议的系统拆分（给做游戏的 AI）

实现时不要按角色写死整局流程，而要做这 8 个系统：

1. **对局状态**：两队士气/星杯/宝石/水晶，牌库，弃牌堆，当前回合，阶段。
2. **玩家状态**：手牌、治疗、能量、指示物、形态、场上牌、横置。
3. **行动合法性**：五种行动 + 启动 + 技能条件。
4. **战斗栈**：主动攻击 / 应战链 / 命中判定。
5. **魔弹链**：方向、伤害、已参与者、圣光/圣盾/传递。
6. **伤害管线**：①–⑥，可插入响应。
7. **资源修正器**：手牌上限、治疗上限、能量上限、士气下限、能否应战、能否成为攻击目标。
8. **技能调度**：按时机收集候选 → 强制/可选/静默 → 互斥组 → 执行效果。

角色技能全部注册到第 8 层，不要在第 4 层写死某个角色。

### 25.4 MVP 验收剧本

用这套最小剧本验证核心规则是否正确：

1. A 用雷光斩攻击 B，B 承受。A 方 +1 宝石，B 摸 2。若 B 原来 6 张则爆 2，蓝方士气 -2。
2. 同上但 B 有 2 治疗并全抵。B 不摸牌，A 仍 +1 宝石。
3. B 用同系应战，指定 A 的队友 C。对 A 未命中；C 若承受，B 方 +1 水晶。
4. A 打暗灭，B 不能应战，只能圣光/圣盾/承受。
5. A 给 B 放中毒。B 回合开始先受 1 点法术伤害，中毒进弃牌。已有中毒不能再放。
6. A 购买：手牌 3 张时成功摸 3 且 +1 宝石 +1 水晶；手牌 4 张时禁止购买。
7. 战绩区 3 星石时合成：摸 3，星石变 0，星杯 +1，对方士气 -1。
8. 圣女打出水系牌，冰霜祷言给自己 +1 治疗，治疗到 2 后再加则溢出丢弃。
9. 天使场上无基础效果时不能发动风之洁净；有中毒时可以移除并触发天使羁绊加治疗。
10. 士气到 0 或星杯到 5，立即结束。

## 附录 C. 一句话规则

红蓝两队共用 150 张牌。每人每回合做一个行动：打攻击、打法术、或购买/合成/提炼。攻击可以同系应战或圣光/圣盾挡。伤害不扣血，改为摸牌；超手牌上限就弃牌扣士气。士气到 0 或星杯到 5 立即赢。角色技能全部挂在「时机 + 条件 + 效果」上，共用同一套伤害时间轴 ①–⑥。
