设计要点
1. 三段式骨架固定不变：顶栏（阶段 + 步骤面包屑 + 设置齿轮）、主体（只放这一步要做的事）、底栏（左＝返回/取消，右＝确认/结束回合），玩家的手和眼睛不用到处找按钮。
2. 主行动用 SVG 线稿图标重画（攻击/法术/特殊/技能/出牌），不再用印着字的金色位图，文字统一放在徽章下方；不可用时直接写原因（如"本回合已用启动技"）。
3. "结束回合 / 放弃额外行动"从主行动里拿出来，作为底栏右侧的次级按钮——它不是一种行动类型，和攻击法术并列容易误点。
4. 多步流程用"牌 ➝ 目标"的小流程图 + 顶栏面包屑表示进度，已选的牌缩略图直接出现在面板里；需要凑张数的用进度点和"已选 X / N"。
5. 状态用边框颜色区分：金＝轮到你，红＝爆牌/警告，无光＝等待别人。"调试"收成右上角齿轮。
